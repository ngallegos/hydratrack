# HydraTrack

Free, login-free hydration tracker. Flutter app for Android and web (PWA).

- Quick-log starred drinks
- Drink categories with hydration factors and colors
- Avatars that fill by category color
- Reminders and notifications
- Opt-in sync: Google Drive or a local folder (Syncthing-friendly)

## Develop

```sh
flutter pub get
flutter analyze
flutter test
flutter run -d chrome
```

New to Flutter/Dart? See [docs/learn](docs/learn/README.md).
